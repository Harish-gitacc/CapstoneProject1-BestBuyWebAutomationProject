BestBuy Automated Testing for Web Applications


The main goal of this project is to combine Selenium with Java, TestNG, and Maven Build to automate the testing of the Best Buy online application. The Page Object Model (POM) architecture is followed in the development of the test automation framework, guaranteeing modular and maintainable code. Any application's automation process is streamlined by the inclusion of Selenium.


 Features of the project


- Model of Page Object (POM): To improve readability and maintainability, the project uses the POM framework to structure and organize the automation code.


TestNG Structure: The testing framework, TestNG, is used to enable the development of thorough test cases and scenarios.


- References: An Excel spreadsheet is used to precisely document all test cases and situations, giving a clear picture of the test coverage.


- HTML Reports : Reports in HTML are produced by the automation framework utilizing

 Cross-Browser Examining With the help of the framework's cross-browser testing features, compatibility and dependability may be tested simultaneously on a variety of browsers, including Chrome, Firefox, Edge, and others.
